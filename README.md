# Смета за 5 минут

«Смета за 5 минут» — простое веб-приложение, в котором можно быстро составить смету или коммерческое предложение и сохранить готовый документ в PDF.

Приложение предназначено для:

- предпринимателей, которым нужно подготовить коммерческое предложение клиенту;
- офисных сотрудников, которые составляют сметы закупок или отчёты о расходах для руководителя.

## Файлы приложения

- `index.html` — структура страницы: заголовки, поля, таблица позиций и кнопки;
- `styles.css` — внешний вид страницы и адаптация интерфейса для телефона;
- `script.js` — расчёты, работа с данными пользователя и подготовка документа к сохранению в PDF.

## Как открыть

Дважды щёлкните по файлу `index.html`. Приложение откроется в браузере и не потребует установки.

## Как проверить

Добавьте две позиции:

- количество 2, цена 15 000 ₸;
- количество 1, цена 8 000 ₸.

Итог должен быть: **38 000 ₸**.
